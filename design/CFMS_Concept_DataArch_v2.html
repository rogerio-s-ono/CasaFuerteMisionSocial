Arquitectura de datos configurable — concepto v2 (decisiones incorporadas)

Las misiones (MercaMadrid, Banco de Alimentos, y futuras: Plaza Mayor, Jurídico…) pasan de estar fijas en el código a ser datos que el Admin crea y edita. Este documento valida el modelo de datos antes de diseñar la pantalla del Admin.

Decisiones confirmadas

  • Contenedor = Misión confirmado (Misión MercaMadrid, Misión Banco de Alimentos…). Modelo plano: cada misión contiene sus actividades directamente.
  • Capacidad por plaza = fija en la plantilla, editable por el Admin confirmado
  • Horario = hora de inicio + duración → el app muestra inicio–fin confirmado
  • El Admin crea/edita todo: misiones, actividades y el catálogo de roles confirmado

01Modelo de entidades

Jerarquía de 4 niveles. Los Roles viven en un catálogo global (editable por el Admin, reutilizable). Una Misión contiene Actividades; cada actividad tiene Plazas-rol.

Clave: una Actividad es una plantilla (no una fecha). Guardamos la regla de recurrencia y generamos las fechas del mes bajo demanda — patrón RRULE (iCalendar), estándar de la industria. Nunca una fila por ocurrencia.

05Cómo se generan las actividades del mes

// hoy:  generateActivities lee SEED_TEMPLATES (fijo en app.js)
// mañana: generateActivities lee CONFIG.misiones (editable por Admin)

CONFIG.misiones (activas)
  → por cada actividad-plantilla (activa)
      → aplicar recurrencia(año, mes)      // fechas del mes
      → calcular fin = inicio + duracionMin // 12:00 +240 → 16:00
      → crear ocurrencia { fecha, inicio, fin, mision, plazas, roles… }
  → ordenar por fecha+hora  →  agenda del mes
Inscripción, vista del líder, lista de espera y "añadir servidor" no cambian: operan sobre las ocurrencias generadas. Solo cambia de dónde salen las plantillas.

06Qué configura el Admin (alcance de la pantalla)

  • Roles (catálogo): crear/editar/desactivar; nombre pt/es, requisito.
  • Misiones: crear/editar/desactivar; nombre, color, descripción, líderes (allowlist).
  • Actividades de cada misión: nombre, hora inicio, duración, recurrencia, notas, activo.
  • Plazas-rol de cada actividad: qué rol + capacidad.
